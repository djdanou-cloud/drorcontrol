DrorControl for macOS: first launch
===================================

This build is for internal use. It is ad-hoc signed and not notarized by Apple (ADR-0010), so
macOS asks once per Mac before opening it.

1. Check the file: compare `shasum -a 256 <file>` with SHA256SUMS published next to it.
2. Copy DrorControl.app to /Applications.
3. Open it once. If macOS says it cannot verify the developer: open System Settings > Privacy
   & Security, scroll to Security and click "Open Anyway", then confirm.
   Or, in Terminal:  xattr -dr com.apple.quarantine /Applications/DrorControl.app
4. Later updates: macOS may ask again for Local Network access, because each build has a new
   ad-hoc signature.

This preview bundles the DrorControl core command-line tool (dc-cli); the graphical cockpit
replaces it when the Qt shell lands. Run it from Terminal, e.g.:
  /Applications/DrorControl.app/Contents/MacOS/dc-cli --help
