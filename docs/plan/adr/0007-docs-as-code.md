# ADR-0007: Documentation as code with enforced CI gates

* Status: proposed
* Date: 2026-10-10

## Decision
MkDocs Material + `mike` versioning; rustdoc, Doxygen, buf/protoc-gen-doc and MAVLink/parameter generators feed one site; Vale, markdownlint, lychee and `mkdocs build --strict` run on every PR; `parity.yaml` entries cannot be marked implemented without handbook page and test ID; screenshots generated by the UI test harness; offline help bundle (SQLite FTS5) built from the same sources.

## Consequences
+ Docs cannot silently rot; single source for online/offline/in-app. − CI time (+~4 min) and writer/engineer coupling (accepted).
